# IngeTrazo Web – Demo

Live demo (GitHub Pages) of **IngeTrazo Web**, a free 3D modeller with Push/Pull that runs in the browser.

- `ingetrazo/` – IngeTrazo Web
- `ext/stairs.js` – an example extension, e.g. `ingetrazo/?ext=../ext/stairs.js`
- `source/` – the complete source code of this build (GPL-3.0-or-later)

This repository contains only built files. `build.sh` rebuilds them from the sibling repository `../ingetrazo-web`.

Based on [IngeTrazo](https://github.com/ingelibre/ingetrazo) (GPL-3.0). License: GPL-3.0-or-later (see `LICENSE`).
